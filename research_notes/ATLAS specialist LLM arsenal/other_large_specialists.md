# Other large specialists (about 70B total and above) for the ATLAS arsenal: discovery catalogue by discipline, as of 2026-10-15

Scope and method. Open-weight models of about 70B total parameters or more, beyond the Principal's named list, that could serve a discipline better than a generalist and that fit alone in the ~164 GiB engine budget at a 3-bit rung or better. Every size below was computed today from the Hugging Face API file trees (sum of `lfs.size` per rung folder or file stem, shards counted, mmproj and imatrix files listed separately; decimal GB = bytes/1e9, GiB = bytes/2^30). llama.cpp support was checked against a local blobless clone of ggml-org/llama.cpp: tag v0.4.1 resolves to commit b29c606e28a01b1bc8c1351026a0fa6e616bf6c4 dated 2026-09-14T17:01:05+03:00 ("bump version to 0.4.1 (#28900)"); "INSIDE" means the commit is an ancestor of v0.4.1 (`git merge-base --is-ancestor`), and architecture presence was read from `src/llama-arch.cpp` and the `conversion/` registry at the tag. Status words: primary = API response, file, card, licence, leaderboard data or git history read directly today (2026-10-15) unless another date is given; reused = a primary fact recorded in `/home/user/AI-Agent/research_notes/ATLAS LLM roster refresh 2026/gap_closure_2026-10-14.md` (read 2026-10-14) and not re-fetched; excerpt = search-snippet only; projection = arithmetic, not a measurement; unverified = no source closes it. The KV-cache figures are computed from each model's config.json as f16 K+V bytes per token = layers-with-full-KV x KV heads x head_dim x 2 x 2 bytes (q8_0 KV halves them); they ignore compute buffers (typically a few GiB) and are estimates. Decode projections use ceiling = 273 GB/s / (active parameters x file-average bits per weight / 8); the measured efficiency band on gfx1151 is 47 to 60 % of that ceiling for large MoE models and about 89 % for a dense 128B (calibration points in KQ2). Facts, not recommendations.

## KQ1. Which large candidates exist for each discipline (catalogue by discipline)

### Takeaway
Genuine large (>=70B) open specialists that fit alone exist in only four disciplines: medicine (Baichuan-M3-235B, AntAngelMed 100B-A6.1B, Apertus-70B-MeditronFO), finance (Ling-3.0-flash-Fin 124B-A5.1B, released 2026-09-03), software engineering (Devstral 2 123B dense, Kimi-Dev-72B, Leanstral 1.5 for Lean 4 proofs) and vision/documents (Qwen3-VL-235B-A22B, InternVL3.5-241B-A28B, GLM-4.6V 106B). Law has one 2026 specialist, GLM Legal (Vals: "open-weight", 86.23 % LegalBench), but no weights repository could be found on Hugging Face and its size is unknown; cybersecurity has only unevaluated community fine-tunes of GLM-5.3-Flash. On the independent boards (Vals, Artificial Analysis, LMArena) the large generalists that fit (MiniMax-M3 at 3-bit, MiMo-V2.6-Flash, Hy3, MiniMax-M2.5/M2.7, Qwen3.5-397B at 3-bit) beat most of the specialists outside their narrow benchmark.
