## Gaps closed

1. **A second non-llama.cpp engine, "Gufo", is in the notes' own primary dataset but was left out. It changes the re-prefill conclusion.** local-llm-benchmarks has Gufo (ROCm 10.0) runs on the 395. A web search found no public page for the engine, so the only description is the results file.
   - V4-Flash-0731 IQ2XXS (antirez mixed file), gufo 0.9.1 (2026-10-09): tg 16.0 → 13.9 at 64K, prefill 497.6 → 387.2. The 2026-09-27 build gave 16.2 → 14.1 and 504.0 → 389.6. With DSpark: 26.9 (09-27 build 29.7).
   - Flash-Next UD-Q4_K_XL, the same unsloth file as the llama.cpp rung: tg 26.1 → 25.6, prefill 1,680.6 → 1,061.0. With MTP-7: 47.6 → 43.9.
