## Key question 4: Known caveats (contamination, saturation, vendor vs independent, reasoning effort, quantised vs BF16/FP8)

### Takeaway
The sources themselves document most of the caveats: AA index versions are not comparable (gpt-oss-120b 58 → 12), Terminal-Bench 2.0/2.1/3.0/4.0 are mixed in the same tables, tau2 v1.0.1 re-graded one domain, BFCL re-weighted for saturation and was rated "Flawed" by Epoch, LiveBench refreshes to counter contamination, and most 2026 open-model coding scores are vendor-run on vendor scaffolds.

### Cited Findings
- AA index version drift: gpt-oss-120b 58 (launch index, Aug 2025) vs 12 (v4.3.2); GLM-5.2 51 vs GLM-5.3 45 "on a newer index version"; "Intelligence Index values should be compared only within the same index version and date" *(search excerpts)* — [AA on X](https://x.com/ArtificialAnlys/status/1952887733803991070); [AA gpt-oss page](https://artificialanalysis.ai/models/gpt-oss-120b); [AA GLM-5.2 article](https://artificialanalysis.ai/articles/glm-5-2-is-the-new-leading-open-weights-model-on-the-artificial-analysis-intelligence-index)
